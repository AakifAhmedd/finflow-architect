Install & updates

Open the hosted app to enable offline use.

iPhone/iPad: open in Safari → Share → Add to Home Screen → Open as Web App (if shown) → Add. Android/desktop: use your browser’s Install app or Add to Home screen menu. Allow the first online download to finish before going offline.

Saved data stays in this browser or installed app. Keep a JSON backup; another browser or installation may have separate storage. Cloud sync needs internet.

Cloud sync (optional)

Leave Gist ID blank to find or create a separate secret Gist named finflow-data. Creating it uploads your current FinFlow backup. A Gist is stored on GitHub and is not encrypted; anyone with its link can read it.

Enter an existing FinFlow Gist ID or link, or leave blank for automatic setup.

Fine-grained tokens can use Gists read/write permission. Your token and Gist ID are saved in this browser. Disconnect removes them. Your token is excluded from backups. Save connection, then Preview cloud before choosing Push to cloud or Pull from cloud. Sync replaces a whole snapshot; it does not merge devices.

Import & backup

Import a FinFlow transaction file to add records, or restore a complete FinFlow backup. Everything happens in this browser.

Choose a file to preview it.

Imports add records and skip previously imported IDs. Existing manual/monthly purchases are not automatically matched; review any overlap. Backups include income, cash movements, and import history, and exclude Gist credentials.

Reset data

Clear all expenses, income, cash movements, import history, monthly expense and income schedules, category changes, and behavior settings stored in this browser. Your Gist connection and the cloud copy are not touched.
